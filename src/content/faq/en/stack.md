question: "Why is this website so plain, and what is it built with?"
order: 5
---

Most websites nowadays ship megabytes of framework code just to show a few paragraphs of text. I prefer to ship static HTML, modern CSS and as little JavaScript as I can get away with, on this site JS is under half a kilobyte. Pages would load immediately even on a weak mobile connection. The site is built with Astro. By the way, the code is open source under AGPL v3 and the text is licensed under CC BY-SA 4.0, because I think knowledge should be shared.
