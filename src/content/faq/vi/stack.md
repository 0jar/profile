---
question: "Sao trang web này đơn giản thế, nó được xây bằng gì vậy?"
order: 5
---

Khá nhiều trang web giờ đều gửi hàng megabyte code framework chỉ để hiện vài đoạn chữ. Mình thích gửi HTML tĩnh, CSS hiện đại và càng ít JavaScript càng tốt, trên trang này JS chưa tới nửa kilobyte. Mình muốn trang web tải nhanh kể cả khi mạng yếu. Trang được xây bằng Astro. Code là mã nguồn mở theo giấy phép GNU AGPL v3 và phần văn bản theo giấy phép CC BY-SA 4.0, vì mình nghĩ công cụ và kiến thức nên được chia sẻ.
